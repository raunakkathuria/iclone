# LESSONS

Every minion follows these lessons. reviewer-minion keeps the list short:

- At most 15 lessons. To add one when the list is full, merge two or drop one.
- A lesson goes in only after the same problem happened twice, or when Gru decided it.
- One line each: a rule you can check in a diff, then where it came from.
  Example: `L-1 Every new API route has a test for a bad request. Why: PR #12 and PR #19.`
- When a test, lint rule or hook can check a lesson, add that check and delete the line.
